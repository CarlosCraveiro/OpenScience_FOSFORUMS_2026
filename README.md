## To compile the presentation

This presentation was built using LaTeX and the **Cookie Beamer Theme**. It was developed and compiled entirely using **Overleaf**, so I am not providing local build instructions or dependency management files.

To compile it yourself, follow these steps:

1. Create a new blank project on [Overleaf](https://www.overleaf.com/).
2. Upload all the repository files to the project (including `.tex` files, images, and the `beamerthemecookie.sty` file).
3. Open the Overleaf **Menu** (top left corner) and change the **Compiler** to **LuaLaTeX** (this is strictly required by the theme to render fonts properly).
4. Click **Recompile**.

Now you should have the PDF ready to look at!
